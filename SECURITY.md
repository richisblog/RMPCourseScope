# Security policy

Please do not publish credentials, private review databases, or production infrastructure details in an issue.

For a suspected security vulnerability, contact the maintainer privately through the contact method listed on [@richisblog](https://github.com/richisblog) rather than opening a public issue. Include affected versions, impact, and safe reproduction steps. Do not include real user data or review exports.

CourseScope is a read-only information lookup project. Do not send credentials or private student information to its public API.
